# Forbidden patterns

A living catalog of rhetorical tics that read as AI-generated. Read this alongside the writing-style rules in `CLAUDE.md`. When you catch yourself about to write one of these, rewrite the sentence instead — don't just swap words.

Add to this file the moment you spot a new pattern in your own output. It only works if it keeps growing.

## Antithesis reframe / negative parallelism

The "It's not X — it's Y" construction, and its variants ("not because X, but because Y", "The question isn't X. The question is Y."). Manufactures false profundity by framing an ordinary statement as a surprising correction.

- Bad: "It's not bold. It's backwards."
- Bad: "Feeding isn't nutrition. It's dialysis."
- Fix: state the point once, directly.

## Staccato pairs

Short declarative fragments strung together for artificial rhythm, often in threes, often answering a rhetorical question.

- Bad: "Not a bug. Not a feature. A fundamental design flaw."
- Bad: "The result? Devastating."
- Fix: write one complete sentence that says the thing.

## Isocolon / metaphor-pairs

Parallel grammatical structures repeated for cadence, frequently stacking abstractions or metaphors that don't add distinct information.

- Bad: "the real workflows, the real tools, the real daily grind"
- Fix: say the one thing that's actually true; don't pad it into a triplet.

## Backward-references

Sentences that lean on referring back to something already said ("as mentioned above," "building on this," "this is why") as fake connective tissue, instead of the logic actually carrying from one sentence to the next.

- Fix: if the connection is real, the next sentence should follow without needing to announce that it follows.
